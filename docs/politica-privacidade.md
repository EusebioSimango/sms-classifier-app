# Política de privacidade — Categorizador SMS

Última actualização: 23 de outubro de 2026.

O Categorizador SMS é uma aplicação para Android que classifica mensagens SMS por categoria, inteiramente no telemóvel. Foi desenvolvida no âmbito de um trabalho de conclusão de curso.

## Que dados são tratados

- O texto, o remetente e a hora dos SMS recebidos.
- Até 100 mensagens já existentes na caixa de entrada, lidas no momento em que a permissão é concedida.

A aplicação não pede o número de telefone do utilizador, localização nem identificadores de publicidade. Se o utilizador autorizar os contactos, lê o nome e o número já guardados no telemóvel apenas para os mostrar na conversa. Essa lista não é enviada para lado nenhum. Se autorizar as notificações, um aviso local mostra o nome ou o número, a categoria e o texto quando chega um SMS. No ecrã de bloqueio só aparece que há uma mensagem nova.

## Para que servem

Apenas para classificar cada mensagem (por exemplo carteira móvel, operadora, bancário ou suspeita) e para permitir a pesquisa e a consulta por categoria dentro da aplicação.

## Onde ficam

A classificação é processada e guardada só no telemóvel, numa base de dados cifrada. A aplicação não tem permissão de acesso à internet, não comunica com servidores e não partilha os SMS com ninguém. A telemetria incluída no motor de classificação está desactivada. Se responderes a um número de telefone, essa resposta é enviada por SMS, através do operador, apenas para esse número.

## Durante quanto tempo

Os dados ficam no telemóvel enquanto a aplicação estiver instalada. São apagados quando a aplicação é desinstalada. A permissão de SMS pode ser retirada a qualquer momento nas definições do Android.
